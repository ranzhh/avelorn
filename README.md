# Avelorn

A toolkit for tabletop wargames, starting with Warhammer: The Old World.
It provides a curated unit and army database behind a queryable API, an army list planner with rule validation, and a combat-math battler.

## Development

After cloning, run `make install` — it installs dependencies (uv) and the git hooks (pre-commit). Other targets: `make test`, `make lint`, `make demo`.
